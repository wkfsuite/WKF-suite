📱 Mobile Device Access

Follow these instructions to access the Leave Management System from your smartphone or tablet.

🌐 Server Address

Use this address in your mobile device's browser:

https://192.168.1.51:8443

HTTP Alternative: http://192.168.1.51:3000
(Only if HTTPS doesn't work)

⚠️ Important: Your mobile device must be connected to the same WiFi network as the computer hosting the server.

📋 Step-by-Step Instructions

1️⃣ Check the WiFi Network

Make sure your mobile device is connected to the same WiFi network as the server.

2️⃣ Open the Browser

Use Chrome, Safari, Firefox, or any modern browser.

3️⃣ Enter the HTTPS Address

Type or copy: https://192.168.1.51:8443

⚠️ Accept the Certificate

The browser will show a security warning. Click:

  • Chrome: "Advanced" → "Proceed to unsafe site"
  • Safari: "Advanced" → "Visit This Website"
  • Firefox: "Advanced" → "Add Exception"

4️⃣ Log In

Use the same credentials you use on the computer.

❓ Troubleshooting

🚫 The Page Doesn't Load

  • Check that you are on the same WiFi network
  • Try restarting the WiFi on the device
  • Verify that the server is running
  • Use the Connectivity Test

🔄 Login Problems

  • Clear the browser cache
  • Try in private/incognito mode
  • Verify username and password
  • Restart the browser

📱 Mobile Optimizations

  • Enable WiFi and disable mobile data
  • On Android: disable "Data Saver"
  • On iPhone: check "Privacy Restrictions"
  • Update the browser to the latest version

💡 Tips

  • Add to Favorites: Save the address for quick access
  • Add to Home Screen: On iOS/Android, add the site to your home screen
  • Stay Connected: Sessions last for 24 hours
  • Use Landscape: Rotate your device for a better view of tables
