📱 Accesso da Dispositivo Mobile

Segui queste istruzioni per accedere al Sistema Gestione Permessi dal tuo smartphone o tablet.

🌐 Indirizzo del Server

Usa questo indirizzo nel browser del tuo dispositivo mobile:

https://192.168.1.51:8443

Alternativo HTTP: http://192.168.1.51:3000
(Solo se HTTPS non funziona)

⚠️ Importante: Il tuo dispositivo mobile deve essere collegato alla stessa rete WiFi del computer che ospita il server.

📋 Istruzioni Passo-Passo

1️⃣ Verifica la Rete WiFi

Assicurati che il dispositivo mobile sia collegato alla stessa rete WiFi del server.

2️⃣ Apri il Browser

Usa Chrome, Safari, Firefox o qualsiasi browser moderno.

3️⃣ Inserisci l'Indirizzo HTTPS

Digita o copia: https://192.168.1.51:8443

⚠️ Accetta il Certificato

Il browser mostrerà un avviso di sicurezza. Clicca:

  • Chrome: "Avanzate" → "Procedi verso sito non sicuro"
  • Safari: "Avanzate" → "Visita questo sito web"
  • Firefox: "Avanzate" → "Aggiungi eccezione"

4️⃣ Effettua il Login

Usa le stesse credenziali che usi sul computer.

🔗 Collegamenti Rapidi

🔧 Test Connettività 🔐 Pagina di Login 📝 Registrazione

❓ Risoluzione Problemi

🚫 La Pagina Non Si Carica

  • Controlla di essere sulla stessa rete WiFi
  • Prova a riavviare il WiFi sul dispositivo
  • Verifica che il server sia in esecuzione
  • Usa il Test Connettività

🔄 Problemi di Login

  • Cancella la cache del browser
  • Prova in modalità privata/incognito
  • Verifica username e password
  • Riavvia il browser

📱 Ottimizzazioni Mobile

  • Attiva il WiFi e disattiva i dati mobili
  • Su Android: disabilita "Risparmio dati"
  • Su iPhone: controlla "Limitazioni Privacy"
  • Aggiorna il browser alla versione più recente

💡 Suggerimenti

  • Aggiungi ai Preferiti: Salva l'indirizzo per accesso rapido
  • Aggiungi alla Home: Su iOS/Android, aggiungi il sito alla schermata home
  • Mantieni Connesso: Le sessioni durano 24 ore
  • Usa il Landscape: Ruota il dispositivo per una vista migliore delle tabelle
