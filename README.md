# WKF Suite - Permission Management System

![WKF Suite](https://img.shields.io/badge/WKF-Suite-blue)

Welcome to **WKF Suite**, a comprehensive permission and leave management system designed for small and medium-sized enterprises.

## Available Versions

This repository contains multiple language variants of WKF Suite:

###  [Italian Version (main-it)](https://github.com/wkfsuite/WKF-suite/tree/main-it)
La versione italiana del sistema di gestione permessi. Completa di interfaccia, documentazione e supporto in italiano.

**Clone:**
\\\ash
git clone -b main-it https://github.com/wkfsuite/WKF-suite.git
\\\

###  [English Version (main-en)](https://github.com/wkfsuite/WKF-suite/tree/main-en)
The English version of the permission management system with full UI, documentation, and support in English.

**Clone:**
\\\ash
git clone -b main-en https://github.com/wkfsuite/WKF-suite.git
\\\

## Quick Features

-  Employee leave & permission tracking
-  Manager approval workflows
-  Admin dashboards & analytics
-  Email notifications (PRO)
-  PDF report generation
-  Desktop app (Windows EXE / Electron)
-  PWA support
-  License management
-  Stripe integration for PRO features

## Getting Started

Choose your language above and follow the setup instructions in the respective branch.

- **Requirements:** Node.js 18+, SQLite3
- **Setup time:** ~5 minutes
